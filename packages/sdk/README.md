# pokeidle-community-sdk

Unofficial community SDK for building [PokeIdle](https://pokeidle.io) extensions. Not affiliated with or endorsed by PokeIdle.

Documentation, examples and the changelog: <https://github.com/duperez/pokeidle-community-sdk>.

Distribution and installation diagnostics: <https://github.com/duperez/pokeidle-community-sdk/blob/main/docs/distribution.md>.
This package is private and experimental; the repository's CI produces installable tarballs without publishing to npm.
Use the accompanying manifest to identify the exact source revision and verify file hashes. CJS, IIFE and declarations
must come from the same artifact, not merely the same `0.0.x` version.
