# Code of conduct

We want this to be a place where anyone can contribute without being treated badly.

**Expected:** be respectful and patient, assume good faith, give and accept feedback about the work (not the person), and
help newcomers.

**Not accepted:** harassment, insults, discrimination, personal attacks, sharing other people's private information, or
using this project to cheat other players or to harm the game or its community.

Because this library can send commands to a game, contributions whose purpose is to abuse the game (exploits,
bypassing its limits, attacking its servers, interfering with other players) are out of scope and will be declined.

**Enforcement:** maintainers may edit or remove comments, issues and pull requests, and block people who break these
rules. To report a problem, use GitHub's private reporting on this repository (Security → Report a vulnerability) or
contact a maintainer through their GitHub profile.

This text applies to issues, pull requests, discussions and any space that represents the project.
